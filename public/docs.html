Community-built AI.

AXON AI is a community project. Volunteers can contribute CPU or GPU training from their own computers. Training is optional and only runs when a volunteer opens the trainer.

Chat uses AXON AI's own from-scratch model. It is still being trained, so its answers are limited. No third-party model service is used.

Each trainer gets different reserved lessons. AXON AI learns from token predictions using approved model updates, but its current model remains experimental.

For a local corpus, download the data generator and run it using Python 3. It creates a roughly 1 GiB text file with more than 15 million synthetic Q&A lines. The EXEs do not require this full file.

Advanced: an optional local AI teacher tool can prepare examples using an already-running llama.cpp-compatible model. Owner-approved examples can enter the training queue. No paid AI provider is required.
