Training workers

The Windows executables are built in the owner's private GitHub repository using the Windows build workflow. The files are not included until the owner publishes them as binary release assets.

GPU-AXON.exe

NVIDIA CUDA training worker. Only download the compiled binary from an AXONAI release published by the project owner. Download GPU-AXON.exe

CPU-AXON.exe

CPU training worker; no dedicated GPU needed. Training pauses when the predicted system RAM exceeds 90%. Download CPU-AXON.exe
