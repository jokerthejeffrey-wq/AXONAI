Getting started

Run the downloaded file on Windows. The first launch requires an internet connection to install the Python runtime and packages. Enter the HTTPS training coordinator address when prompted.

The training coordinator is a separate service; the AXONAI chat website is not the coordinator. Training begins only after you start the worker. The 90% RAM threshold is a best-effort admission limit, not a hard cap.
