01 / Open the launcher

On Windows, extract the ZIP and double-click START_CPU.cmd or START_GPU.cmd. If needed, the launcher offers to install Python 3.12, then creates an isolated environment and installs dependencies. NVIDIA GPU training requires a compatible driver. Linux/macOS users need Python 3.11 or 3.12 installed first.

02 / Connect

Paste the backend URL when the console asks. Or use the commands below. The setup asks before installing packages and before starting compute.

03 / Train a few lessons

A job contains at most eight lessons, each trained for one step. Every topic group has at most four scheduled uses in the shared ledger. Common greetings share one group. Failed jobs also consume their reservations so retries cannot silently repeat lessons.

Uploads are reviewed and evaluated before publication. Add --threads 2 to limit CPU threads. Press Ctrl+C to stop. The program does not scan personal files or train on chat messages.

Understanding the limit

Four uses is a repetition budget, not proof that a skill has been learned. The starter curriculum is a pipeline demonstration, not enough to train a capable general assistant. Semantic groups are curated by the owner; unseen paraphrases cannot be classified perfectly.
