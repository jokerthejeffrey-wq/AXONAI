AXON AI: one Vercel project, no separate coordinator.
Upload AXONAI_Vercel to your GitHub repository root.
Vercel Project > Settings > Root Directory: AXONAI_Vercel
Build: npm run build   Output: public   Install: npm install   Node: 22.x
Connect Neon Postgres + PUBLIC Vercel Blob store, add AXON_OWNER_TOKEN as a secret.
Check https://YOUR-WEBSITE/api/status (training_available must be true).
Edit AXONAI_Vercel/public/worker-config.json with your website production URL, commit and redeploy.
See README.md for complete setup and review instructions.
