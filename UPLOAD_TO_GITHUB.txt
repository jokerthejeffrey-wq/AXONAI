AXON AI — INSTALL
1. Upload the contents of the AXONAI_Vercel folder to the directory used as Vercel's Root Directory.
2. Set Framework Preset Other, Node.js 22.x, Build Command npm run build, Output Directory public.
3. Enable AI Gateway for the Vercel project. Vercel OIDC supports automatic authentication; alternatively set a real AI_GATEWAY_API_KEY in Vercel Production settings.
4. Redeploy without the previous build cache. Test https://axonai-theta.vercel.app/chat.
5. Connect Neon + Blob in Vercel Storage to enable persistent training. Without these, the website and EXE files can still deploy but training will report unavailable.
